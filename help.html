英数逆算プランナー
使い方

模試や定期テストの日から逆算して、今日やる範囲を決めるアプリです。

01最初の10分でやること

この順番でやると、その日から動き出せます。

  1. 「逆算」タブで試験を登録。模試なら科目ごとに1件（英語・数学）。定期テストも科目ごとに1件です。
  2. 「教材」タブで本棚に教材を追加。よく使う参考書はプリセットを選べば章まで自動で入ります。総数を1つ入れるだけです。
  3. 「設定」タブで1日の上限を決める。最初は控えめに。あとで実測から自動提案されます。
  4. 「逆算」タブの「プランを組み直す」を押す。これで今日から仕上げ日までの範囲が全部決まります。
コツ
教材は最初から全部入れなくて大丈夫です。いま使っている2〜3冊だけで始めて、増えたら足すほうが続きます。

02毎日の使い方

朝：「今日」タブを開く。今日やる範囲と、それにかかる見込み時間が出ています。

勉強中：タスクの右の ▶ を押すと、その教材で時間の計測が始まります。

終わったら：タスクの丸をタップしてチェック。これで進捗が進みます。

大事
教材の進捗はタスクにチェックを入れたときだけ進みます。逆に言うと、やらなかった分は消えずに残り、次にプランを組み直したときに戻ってきます。サボっても計画が崩れないのはこのためです。

記録の4つの入り口

「今日」タブの記録するに集約されています。上のボタンで切り替えます。

入り口使う場面
まとめ書き「シス単 30分／塾の授業 2時間」のように一気に書く。教材は自動で振り分け

加えて、タスクにチェックを入れると時間を聞かれます。これが普段の主な入り口です。

04逆算はどう計算しているか

中身を知っておくと、数字が変わった理由がわかります。

仕上げ日から逆算する

締切は試験日そのものではなく、その手前の「仕上げ日」です。模試なら7日前（設定で変更可）、定期テストは最大2日前。直前を総復習に空けるためです。

上限まで前倒しはしない

毎日「仕上げ日までに終わらせるには1日いくつ必要か」を計算し直して、その分だけ配ります。上限は「これ以上は無理」という天井であって、目標値ではありません。上限を超えるときだけ、重要度の高い章が優先されます。

優先度の決め方

優先度 ＝ 重要度 × （残り ÷ 仕上げ日までの日数）

重要度が高いほど、そして締切が近いほど優先されます。日が経つほど分母が小さくなるので、放置した章は自然と前に出てきます。

細切れにしない

ペースが1日1件未満の章は、いったん「借り」として溜めて、まとまってから出します。「1ページだけ」というタスクが延々並ぶのを防ぐためです。

05定期考査

模試の逆算とは別枠です。「考査」タブで管理します。

  1. 考査を作る（例: 2学期中間考査）
  2. 科目を足す。科目ごとに試験日・目標点・満点
  3. 範囲を足す。「教科書 Lesson5-7, 36」のように名前と量を1行ずつ

科目ごとの試験日から逆算して日割りされます。3日目の科目は初日より2日多く使える、という計算が自動で入ります。

直前3日は総復習
試験日の3日前を仕上げ日にして、それまでに範囲を一周する配分になります。残りの3日は範囲消化ではなく、間違えたところの潰し込みと暗記にあてる想定です。

「今日やること」に各科目のその日ぶんが出て、「済」ボタンで進みます。

小テスト

同じ「考査」タブの上のほうで管理します。名前・実施日・科目・範囲・量を入れておくと、2日前から「今日」タブに出ます。頻度が高いので、早くから出しても邪魔になるだけだからです。

残りを残り日数で割ったぶんが「今日のぶん」として出て、「済」で進みます。終わったあとは ✎ から点数も記録できます。平均点が出ます。

06周回のしくみ

参考書は1周では身につかないので、最初から3周ぶんで逆算します（設定で1〜5周）。

1周走り切ると「今日」タブに確認カードが出ます。ここで手応えを答えると、次の周の量が決まります。

手応え次の周
◯ 定着25%だけ。2周目以降で◯を押すとその章は卒業
△ あやふや60%
× 全然100%（もう一度ぜんぶ）

手応えを答えるまで次の周のタスクは出ません。 惰性で回るのを防ぐためです。

07着地予測の読み方

「逆算」タブの下のほうにあります。直近14日の実測ペースで進めたら、いつ終わるかを科目ごとに出します。

英語　21日おくれ

残り 370p ・ 実測 5.0p/日（直近14日）

このペースだと 10/18 に完了。間に合わせるには1日 7.0p（あと+2.0p）必要です。実測だと1日およそ 31分 かかります。

「7ページ」だけだと多いか少ないか判断しづらいので、実測から時間に換算した数字も出しています。ここを見て無理そうなら、周数を減らすか教材を絞るかを決めてください。

記録が3日ぶんに満たないうちは予測しません。始めたばかりのときに脅されても意味がないからです。

08教材と単位

教材ごとに数え方を選べます。

単位表示向いている教材
ページp.13–14参考書、問題集
問No.1–3講習テキスト、演習書
語No.121–139単語帳、熟語帳

1日の上限は、これらをまとめて「件」として数えます。1語と1ページを同じ1件とするのは粗いので、実際の負荷は「今日」タブの見込み時間で確認してください。

教材が増えてきたら

同時に回せるのは3〜4冊までです。それ以上あると1冊が回ってくる間隔が空いて、どれも中途半端に進みます。

いま使わない本は、本のカードを開いて「いまは使わない（棚上げ）」。逆算から外れて、残りの本に時間が集まります。進捗と記録はそのまま残るので、いつでも「戻す」で復帰できます。

逆算に載っている本が5冊以上になると、本棚の上に知らせが出ます。

目次の写真から一発で登録

「教材を追加」の下にある「📷 目次の写真から一発で登録」で、章名と分量をまとめて読み取れます。1回およそ3円。

目次に開始ページが並んでいれば、次の章との差から各章の分量を計算します。単語帳の語番号（0001-0046 など）にも対応します。読み取った数字は必ず確認してください。

実測から上限を決める

学習時間と消化量がたまると、設定タブに「1ページに何分かかっているか」が出ます。使える時間を入れると、現実的な上限を提案してくれます。「この値を上限にする」を押して保存するだけです。

09AI機能（任意）

設定タブで Claude の APIキーを登録すると、2つの機能が使えます。キーがなくても他の機能はすべて動きます。

AIアドバイス（分析タブ）

ボタンを押したときだけ生成します。目標との差、模試の分野別成績、教材の進捗、学習時間、着地予測を渡して、来週の重点を出します。

成績表の読み取り（分析タブ）

模試ナビの「設問別」の画面を撮って読み込ませると、設問名・得点・配点・全国平均が自動で埋まります。1回およそ2円。

画像は縮小してから送られます。読み取った数字は必ず目で確認してから保存してください。受験日は画像に写っていないことが多いので、自分で直す必要があります。

AI演習（分析タブ）

試験形式を選ぶと、その傾向に合わせたオリジナル問題を8問作ります。選択式は自動採点、記述式はAIが部分点をつけて指摘します。実在の過去問は使いません。

Sonnet 5約2円約7円約2円

キーはこの端末の中だけに保存され、送信先は api.anthropic.com のみです。データを書き出すときもキーは含まれません。

10ポモドーロ

設定でオンにすると、計測中に集中25分／休憩5分を自動で切り替えます。切り替わるときに端末が振動し、通知を許可していれば通知も出ます。

記録されるのは集中していた時間だけです。65分計測して休憩が10分あれば、55分が記録されます。

11データとバックアップ

いちばん重要な注意
何もしなければ、データはこの端末のブラウザの中だけにあります。機種変更、ブラウザのデータ削除、端末の故障で全部消えます。

クラウド保存（おすすめ）

GitHubの非公開Gistにデータを預けられます。設定は一度きりで、あとは自動です。

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Generate new token (classic) を押す
  3. 権限は gist だけにチェック（他は不要）
  4. 作られた ghp_ で始まる文字列をコピー
  5. アプリの設定タブ「クラウド保存」に貼って、トークンを保存して同期する

以降は、データが変わってから2分ほどで自動的に送られます。アプリを閉じるときにも送ります。「手動だけ」に切り替えることもできます。

別の端末で使う

新しい端末で同じURLを開き、同じトークンを貼って「クラウドから読み込む」を押すだけです。保存先のIDは自動で探すので、控えておく必要はありません。

送られないもの
Claude の APIキーと GitHub のトークン自体は、クラウドには送りません。新しい端末では入れ直してください。

ファイルに書き出す

クラウドを使わない場合や、念のため手元にも残したい場合は、設定タブの「JSONに書き出す」を使ってください。復元は「JSONから読み込む」です。

クラウド同期も書き出しも7日以上していないと、「今日」タブに知らせが出ます。

12通知について

このアプリは時刻を指定したリマインダーを出せません。サーバーを使わない設計だと、Webの仕組み上どうしても正確な時刻に通知できないからです。

代わりにAndroidの標準アラームを使ってください。「逆算プランナーを開く」というラベルで、夜（22時ごろ）と朝の2本立てにするのがおすすめです。端末を再起動しても消えず、確実に鳴ります。

13困ったとき

直したはずなのに画面が古いまま

アプリを一度完全に閉じて開き直してください。それでも変わらなければ、ブラウザで ?v=2 のような文字列をURLの末尾に付けて開くと、新しいものが読み込まれます。

プランを組み直したらタスクが消えた

完了済みのタスクは残り、未消化のぶんだけが組み直されます。消えたように見えても、その範囲は仕上げ日までのどこかに再配置されています。

「間に合いません」と出るが、どうすれば

3つの手があります。周回数を減らす（設定）、教材を絞る（重要度の低い章を削る）、1日の時間を増やす。着地予測の数字を見ながら決めてください。

章の数やページ数がプリセットと違う

プリセットは目安です。本棚で教材を開いて「章をまとめて作る」から作り直すか、章を1つずつ直してください。

クラウド保存は無料？他人に見られない？

無料です。作られるのは非公開（secret）のGistなので、URLを知らない人からは見えません。リポジトリの一覧にも出ません。ただし暗号化はされていないので、トークンを他人に渡さないでください。

オフラインでも使える？

使えます。ホーム画面に追加していれば、圏外でも起動します。AI機能だけは通信が必要です。

科目を英数以外に増やしたい

教材タブの一番下「科目」から追加できます。追加した科目は計画・タスク・学習時間で使えますが、模試の分野別分析とAI演習は英語・数学のみです。
